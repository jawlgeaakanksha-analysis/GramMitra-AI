# 🌾 GramMitra - Marathi Voice AI for Latur Farmers

**Track 4 - Agricultural Intelligence | Team: Aakanksha_Solo_Latur**

### The Problem
Latur, Marathwada madhil 10 lakh+ shetkari ani gramin mahilana English yet nahi. Tyamule Majhi Ladki Bahin, PM Kisan yojnechi mahiti, APMC bhav, havaman mahiti milat nahi.

### Our Solution - GramMitra
Ek Marathi bolnara AI Mitra!

- 🗣️ Marathi Voice Input (Google Cloud Speech-to-Text mr-IN)
- 📸 Crop Disease Detection (Gemini 1.5 Pro Vision)
- 💰 Latur APMC Market Price - Rozche bhav Marathi madhe
- 🌦️ Weather Alerts
- 🏛️ Sarkari Yojna Guidance - Majhi Ladki Bahin & PM Kisan

### Tech Stack
Gemini 1.5 Pro, Google Cloud Speech-to-Text, Cloud Run, Python

### Impact
Bhashacha adthala dur karun shetkaryanche utpanna vadhavne.
